# PingPong Score · 乒乓计分器

一个零依赖、单文件的乒乓球比赛计分器，打开 `index.html` 即可使用，无需安装、无需联网。

## 功能特性

- 实时计分：支持双方球员加分  减分，键盘 `A``Z`（球员一）、`L``M`（球员二）快捷操作。
- 局  盘管理：可设置 `best of`（几局几胜）、每局目标分（默认 11 分），自动判定胜负与赛点。
- 发球权与换边：支持手动换边（`S` 键）、自动换发、决胜局换边逻辑。
- 中英文界面：右上角一键切换 `中文  English`。
- 比赛统计：记录各局比分历史、总得分、最长回合、最大领先分。
- 本地保存：刷新页面不丢分，自动存入浏览器 `localStorage`。
- 一键分享：可复制本场最终比分结果。

## 使用方法

1. 直接用浏览器打开 `index.html`。
2. 在顶部设置比赛规则（局数、每局分数、首发等），输入双方球员名。
3. 点击 `+` 计分，或用键盘快捷键操作。
4. 点 `撤销` 回退上一分，`换边` 交换左右位置，`重置` 开始新比赛。

## 快捷键

 键位  操作 
 ----  ---- 
 `A`  `Z`  球员一 加  减 1 分 
 `L`  `M`  球员二 加  减 1 分 
 `S`  换边 
 `U`  撤销上一步 
 `R`  重置比赛

## 技术说明

- 纯原生 `HTML / CSS / JavaScript`，无任何第三方依赖。
- 状态通过 `localStorage` 持久化，无后端、无构建步骤。
- 适配桌面与移动端，支持触屏点击与键盘操作。
